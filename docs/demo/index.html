HTM Mortgage Note Tokenization Close-of-escrow paper → OCR → canonical loan → XRPL Devnet (MPT · XLS-65 vault · XLS-66 loan · 3-bucket servicing). Everything below is read live from Devnet or produced by npm run demo. Synthetic data only.

1 · The flow

Scan4 closing docs: Closing Disclosure, Form 3200 Note, Form 3013 Deed of Trust, recorded deed
OCR + tie-outtesseract → canonical loan JSON; P&I, LTV, cash-to-close, sweep must balance
TokenizeMPT HTMN1, 45,000,000 units = $450,000.00, KYC-gated, docs sha256 in metadata
FundXLS-65 private vault (attested depositors) → XLS-66 LoanBroker + two-party LoanSet
Servicemonthly sweep → P&I LoanPay · tax impound · insurance impound → escrows to payees

Run it yourself

git clone https://github.com/vanfwilson/xrpl-mortgage-tokenizing-htm && cd xrpl-mortgage-tokenizing-htm
npm ci && npm run ingest && npm run print && npm run scan -- out/print/closing-package-stack.pdf && npm run demo

Or press “Run workflow” on the Devnet demo Action; it reruns everything on a fresh Devnet wallet set and republishes this page.
